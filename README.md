# Foxydev UI 

My great frontend. More to come.

## First-time setup

1. Install dependencies:
   ```
   npm install
   ```
2. Copy the example env file and adjust as needed:
   ```
   cp .env.example .env.development
   ```
   By default this points `VITE_API_BASE_URL` at `http://localhost:7050`, where the backend is expected to be running locally.
3. Start the dev server:
   ```
   npm run dev
   ```
